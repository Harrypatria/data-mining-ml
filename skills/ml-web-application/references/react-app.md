# React workbench reference

## File map (`templates/ml-web/`)

| Path | Role |
|---|---|
| `design-tokens.json` | Tastemaker source of truth (ink-graphite primary, Okabe-Ito data colors, IBM Plex) |
| `src/styles/tokens.css`, `tailwind.v4.css`, `tailwind.v3.cjs` | Generated by the token builder; never edited by hand |
| `src/styles/index.css` | Tailwind import, token imports, extra semantic utilities |
| `src/api/schema.d.ts` | Generated from the service's OpenAPI document |
| `src/api/client.ts` | Typed fetch wrapper, error kinds, session id |
| `src/api/sse.ts` | POST plus server-sent events reader for the narrative endpoint |
| `src/hooks/useWorkbench.ts` | Schema, model info, debounced what-if, sensitivity grid, explainer chat state |
| `src/components/ui/*` | shadcn-style primitives on Radix (button, slider, select, switch, toggle group, tooltip, sheet, input, feedback) |
| `src/components/PredictorPanel.tsx` | Schema-driven controls |
| `src/components/ResultPanel.tsx` | Probability, label, delta, extrapolation warning |
| `src/components/Charts.tsx`, `ChartsSection.tsx` | Contribution bars, sensitivity line |
| `src/components/ExplainerChat.tsx` | Streaming chat with fallback notice |
| `src/components/Panels.tsx` | Scenario table, model drawer, status panel |
| `src/test/*` | Vitest setup, fixtures, workbench tests |
| `deploy/nginx.conf.template`, `Dockerfile` | Production image; nginx proxies `/api` and injects `X-API-Key` |

## Data flow

```
slider change -> profile state -> useDebounced(250 ms) -> useQuery(["whatif", profile])
                                   |-> AbortSignal cancels the previous request
                                   |-> keepPreviousData keeps the last result while pending
Explain this change -> streamNarrative(scenario, question, history) -> meta, token..., done
                                   |-> done.source == "template" shows the fallback notice
```

## Error kinds to states

| HTTP | Kind | UI |
|---|---|---|
| network failure | unavailable | Service unavailable panel with retry |
| 503 | not_ready | Model not ready panel |
| 429 | rate_limited | Inline notice; chat says the explanation limit was reached |
| 401, 403 | unauthorized | Access refused panel |
| 400, 413, 422 | invalid | Inline message with the server detail |
| other | server | Generic error with retry |

## Accessibility

Sliders expose `aria-label` (label with unit) and `aria-valuetext` (formatted value); tooltips are focusable triggers; charts have an `sr-only` table; the result region is `aria-live="polite"`; a skip link targets the workbench; color is never the only signal (signed numbers, icons, text).

## Tests

```bash
npm run typecheck && npm test && npm run build && npx tastemaker scan src --project
```

- Debounce: three ArrowRight presses produce one `/v1/whatif` request with the final value.
- States: 503 renders "Model not ready"; a rejected fetch renders "Service unavailable".
- Streaming: SSE tokens render progressively; `source: "template"` shows the fallback notice; the request body never contains explanation values.
