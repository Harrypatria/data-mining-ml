## Environment: Visual Studio Code
- Prefer `# %%` percent-format `.py` files run in the Interactive Window; open `.ipynb` files with the Jupyter extension when a notebook is required.
- Inspect frames with Data Wrangler instead of printing them.
- Use the workspace tasks: scan the project, run the clean-execute check, start the API, start the web dev server; debug the API with the FastAPI launch configuration.
- Select the project interpreter (`.venv`) before running cells so versions match the pinned requirements.
